# 🛡️ HerRoute: Woman Safety & Secure Navigation Platform

> A smart mobility and navigation web application prioritizing user safety through dynamic risk mapping and community-driven incident reporting.

## 🚀 Overview
HerRoute was developed to address public space safety by providing a secure commute ecosystem. This frontend application integrates with MLOps Risk Prediction APIs to map and display safety levels dynamically. Built with a strong focus on User-Centered Design (UCD), it ensures an intuitive and accessible interface for critical safety situations.

## ✨ Key Features
* **Dynamic Safety Heatmap:** Consumes REST APIs to display real-time machine-learning-driven risk predictions on interactive maps.
* **Safe Commute Insights:** Recommends secure routes based on historical and real-time risk data.
* **Anonymous Incident Reporting:** Secure, privacy-aware reporting mechanism with strict form validation to ensure data integrity without compromising user identity.
* **Responsive & Cross-Browser Design:** Highly optimized UI/UX ensuring seamless operation across various devices and browsers during emergencies.

## 🛠️ Tech Stack
* **Frontend:** React.js, TypeScript, Vite
* **Styling:** Tailwind CSS
* **Integration:** RESTful APIs (MLOps Risk Prediction)

## 💡 Engineering Highlight
Focused on bridging complex Machine Learning backend models with an intuitive, zero-latency user interface, ensuring that critical safety data is delivered efficiently to the end-user.
